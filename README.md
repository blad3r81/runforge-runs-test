# Runforge Runs

Страница запусков AI-агентов на React, TypeScript и Vite. Данные демонстрационные: локальный сервис возвращает Promise с задержкой, реального backend и запуска агентов нет.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес из терминала. `npm run build` собирает приложение, `npm test` запускает тесты Vitest и React Testing Library.

## Проверка

- Выберите статус и введите название или репозиторий: условия работают одновременно.
- Откройте запуск, проверьте данные, логи и результат; закройте кнопку, фоном или клавишей Escape.
- Для проверки ошибки откройте `/?mockError=1`: первый запрос завершится ошибкой, кнопка повторит его успешно. Загрузка видна благодаря задержке 650 мс.
- Введите запрос без совпадений и сбросьте фильтры. Проверьте мобильную ширину от 360 px.
- Дополнительно: переключите сортировку по дате между новыми и старыми запусками.

## Структура

`src/data.ts` — типы, mock-данные и сервис. `src/App.tsx` — состояние страницы, фильтры, список и детали. `src/style.css` — стили и адаптация. `src/App.test.tsx` — тесты поиска, статуса и деталей.
